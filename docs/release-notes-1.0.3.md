## 更新说明正文（直接粘贴这段）

```
【新增】听书朗读
阅读时点击页面右上角的喇叭图标，即可开始朗读当前章节。
朗读过程中自动翻页跟随，进度实时显示；可随时暂停、继续或停止。

【新增】整章连续播放
按整本书章节组织朗读内容，翻页不再打断朗读，听到哪页字就亮到哪。

【优化】停顿更自然
重新调整了标点、引号和中英文混排时的停顿处理，
消除了莫名其妙的卡顿和不受控的连读。

【隐私】朗读不联网
朗读使用系统内置语音离线合成，整个过程中没有任何网络请求。
```

正文共 4 条 / 约 200 字。三条设计取舍说明（不上传，给党哥自己看）：

1. **不提「音色选择」**：当前只有系统内置一个中文音色可稳定使用（另一男声需联网下载，
   本版不做下载入口，所以对用户不存在「选音色」这件事——说了就是空头支票）。
2. **不提「引擎/技术名词」**：用户视角只有「能听、跟着翻页、停得下来」三件事。
3. **「不联网」单列一条**：这是本产品对隐私敏感用户的核心卖点，且与上架口径
   （零网络权限，审核最易放过的形态）一致，写明它反而降低审核疑虑。
